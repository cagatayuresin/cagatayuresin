## ⚙️ About Me

**DevOps / Platform Engineer** with **4+ years** operating **production Kubernetes** across **50+ enterprise environments** — on-premises and hybrid, under strict data-residency and security requirements.

- 🚀 **GitOps as a daily driver** — Argo CD (+ Image Updater), GitLab CI/CD pipelines with SonarQube quality gates
- 🧯 **Reliability end to end** — weekly on-call rotations, incident response & root-cause analysis (container runtime failures, etcd overload, disk pressure)
- 📡 **Built Observer** — an in-house monitoring, alerting & anomaly-detection platform (InfluxDB · Grafana · RabbitMQ · Telegram alerting)
- 🤖 **AI infrastructure in production** — vLLM / Ollama model serving and RAG retrieval for an SAP-integrated enterprise AI product (semantic search accuracy 65% → ~95%)
- ☁️ **Currently** — Terraform on AWS (R&D provisioning), preparing **AZ-900**, and writing my M.Sc. thesis on **LLM-based network intrusion detection** (Zeek + LangChain)
- 🏠 **Homelab** — K3s on a VPS with Traefik, cert-manager & Let's Encrypt, self-hosting my own services
- ✍️ Writing about DevOps & infrastructure at **[cagatayuresin.com](https://cagatayuresin.com)**
